# 台本フォーマット（Gist / 自作台本用）

`script_gist` に渡す台本の仕様。取り込んだ後、**音声合成・Remotionレンダリングは通常と全く同じ**に走る。
つまり59種ピクトグラム・グラフ・字幕・カメラワーク・BGM等の演出はすべてそのまま効く。

## 2つの書き方

**A. ナレーションだけ書く（おすすめ・らくちん）**
文章だけ渡せば、AIが内容を理解して各シーンの visual（ピクトグラム/グラフ）・ふりがな・幕・背景色を自動で割り当てる。
visual を1つも書いていない台本を渡すと、この「AI演出」モードで処理される。

- 平文（1文＝1シーン。改行や 。！？ で自動分割）:
  \`\`\`
  深夜2時。親指だけが動いている。
  選択肢は多いほど、人を選べなくする。
  そんなことを、考えすぎてみました。よろしければ、チャンネル登録と高評価をお願いします。
  \`\`\`
- 文字列の配列 / narration だけのJSON / \`{ "title": "…", "text": "全文…" }\` でもOK。
- ※ AI演出は Claude を使うため少額のトークン費用がかかる（20分で概ね¥100〜150）。ナレーション本文は一字一句変更されない。

**B. visual まで自分で指定する（完全手動・Claude不使用＝¥0）**
下記のフォーマットで各シーンに visual を書けば、AIは呼ばれず、そのまま映像化される。細かく演出を制御したいとき用。

---

以下は **B（visual まで自分で書く）** の完全仕様。

## トップレベル

```json
{
  "title": "なぜ〜なのか【学問A×学問B】",
  "theme": "扱う社会事象を一文で（任意）",
  "bgm_direction": "Dark ambient piano, quiet and contemplative.（任意・英語）",
  "scenes": [ /* シーンの配列 */ ]
}
```

- `title` 必須。`theme` / `bgm_direction` は任意（無ければ既定BGM指示）。
- `bgm_direction` はFreesound検索・BGM生成のヒントになる。

## シーン（1シーン = 1文 ≒ 5秒）

```json
{
  "id": 1,                 // 任意（無ければ自動で連番）
  "act": 1,                // 任意 1〜5（無ければ直前の幕を継承）
  "narration": "画面に流れる字幕＆読み上げる本文。1文。",
  "reading": "誤読しやすい漢字をひらがなに開いた読み上げ専用文（任意）",
  "concept_color": "charcoal",   // 任意 dark-navy | charcoal | pitch-black | daylight | dusk | warm
  "visual": { /* 下記いずれかの型 */ }
}
```

- **必須は `narration` と `visual` のみ。** 他は自動補完される。
- `reading` を書くと読み間違いが減る（句読点の位置は narration と一致させること）。
- `concept_color`: 暗=dark-navy(夜・思索)/charcoal(データ)/pitch-black(断定・結び)、明=daylight(昼の情景)/dusk(夕暮れ)/warm(暖色の回想)。明トーンを2〜3割混ぜると画面が単調にならない。

## visual の型（この10種から選ぶ）

### figure — 動くピクトグラム（映像の主役）
```json
{ "type": "figure", "figure": "crowd", "label": "終わらない椅子取りゲーム" }
```
`figure` は次の60種から選ぶ（他の名前を書くと person になる）:
```
person crowd couple family handshake conflict isolation hierarchy queue blame
applause leader bystander brain heart mask eye anxiety lightbulb addiction
thought tears dream money city factory scale gavel stairs cage chains target
trophy podium contract shopping crown clock hourglass candle tree seed path
door mountain smartphone notification screen camera network echo dna atom
evolution arrowUp arrowDown cycle crossroad question village
```

### keyword — 中央に浮かぶ抽象語
```json
{ "type": "keyword", "keyword": "自己家畜化" }
```

### dialogue — 人物シルエット＋吹き出し
```json
{ "type": "dialogue", "line": "また日曜が終わる" }
```

### stat — 大きな数字
```json
{ "type": "stat", "value": "150人", "label": "ダンバー数 — 脳が保てる関係の上限" }
```

### chart — 横棒グラフ（リッチ表示対応）
```json
{ "type": "chart", "title": "なぜ地元を出た?", "unit": "%",
  "subtitle": "青森県「県外へ転出した理由」調査",
  "items": [ { "label": "県外に働きたい職場", "value": 45.1 }, { "label": "親元を離れたかった", "value": 35.2 } ],
  "highlight": 1,
  "annotation": "進学組では 46.4% ≒ 2人に1人" }
```
`subtitle`(出典)・`highlight`(強調する項目のindex、アンバー表示)・`annotation`(下部の注釈ボックス)は任意。

### line — 折れ線グラフ（推移。最終点を強調）
```json
{ "type": "line", "title": "出生率の推移", "unit": "",
  "points": [ { "label": "2022", "value": 1.04 }, { "label": "2024", "value": 0.96 } ] }
```

### units — ドットの集団（割合の実感。消える側が赤く消滅）
```json
{ "type": "units", "total": 100, "value": 96, "label": "次世代に残る人口" }
```

### table — 表（行が順に出現）
```json
{ "type": "table", "title": "自動化の三段階",
  "headers": ["段階", "主体", "人間の役割"],
  "rows": [ ["道具化", "人間", "全工程"], ["自律化", "機械", "監督のみ"] ] }
```

### comparison — 左右対比
```json
{ "type": "comparison", "left_title": "サバンナの脳", "right_title": "都市の環境",
  "left_items": ["数十人", "顔見知り"], "right_items": ["数百万人", "匿名"],
  "center_label": "≠" }
```

### list — 箇条書き
```json
{ "type": "list", "title": "承認の三段階", "items": ["存在", "所属", "序列"] }
```

## 最小の完全な例

```json
{
  "title": "なぜ我々は棚の前で立ち尽くすのか【行動経済学×進化心理学】",
  "bgm_direction": "Dark minimal ambient with sparse felt piano. Quiet, uneasy.",
  "scenes": [
    { "act": 1, "narration": "深夜2時。親指だけが動いている。",
      "visual": { "type": "figure", "figure": "smartphone", "label": "終わらないスクロール" } },
    { "act": 2, "narration": "選択肢は多いほど、人を選べなくする。",
      "reading": "せんたくしはおおいほど、ひとをえらべなくする。",
      "visual": { "type": "stat", "value": "3%", "label": "24種類のジャムを買った人の割合" } },
    { "act": 5, "narration": "そんなことを、考えすぎてみました。よろしければ、チャンネル登録と高評価をお願いします。それでは、次の動画でまたお会いしましょう。",
      "visual": { "type": "keyword", "keyword": "考えすぎる葦" } }
  ]
}
```

## 実行

GitHub Actions「Auto Generate Video」の `script_gist` 欄に GistのURL / ID / 生JSON URL を入れて実行。
ローカル確認は `npm run load:script -- --gist=<url>`（script.json に取り込むだけ）。
