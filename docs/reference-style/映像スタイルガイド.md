## 1. 最重要の結論

### ❗ 1-1. 「明るい背景を増やす」は誤りだった（922コマの実測で確定）

以前「ずっと暗い背景」という指摘を受けて明トーンを約38%まで機械的に引き上げたが、
**実物は圧倒的に暗い。** 922コマの平均輝度を実測した結果:

| 指標 | 実測値 |
|---|---|
| 平均輝度 | **45 / 255**（約18%） |
| 中央値 | 34.5 |
| 暗い（輝度<40） | **63.2%** |
| やや暗い以下（<70） | **85.5%** |
| 暗くない（≥100） | **6.7%** |
| 明るい（≥140） | **2.7%** |

→ 現在の実装目標「明トーン1割」は**実測レンジ内（暗くない=6.7%）で妥当**。
これ以上明るくしてはいけない。

色相も実測した（彩度0.25以上の画素）:

| 色相帯 | 比率 |
|---|---|
| 青 | 29.9% |
| シアン | 23.1% |
| **橙・琥珀** | **19.9%** |
| 赤 | 12.2% |
| 藍・紺 | 4.3% |
| その他 | 10.6% |

**寒色系（青＋シアン＋藍）が58%、暖色アクセント（橙・琥珀）が20%。**
平均彩度は0.46 — 「くすんだフラット」ではなく、**暗いが色は乗っている**。

真の差は明暗ではなく**「暗さの質」**である。

| | 現状の実装 | 参照チャンネル |
|---|---|---|
| 背景 | 平坦な放射グラデーション1枚 | 奥行きのある**情景**（夜景・森の断面・山並み・広間） |
| 光 | 中央のぼんやりした光 | **体積光**（スポットの光条）・窓明かり・ボケ・強いグロー |
| 主役 | 中央に浮くアイコン1個 | 環境の中に**配置**された人物・物体 |
| 密度 | 要素1〜2個 | 背景に無数の小要素（窓・人・棚・張り紙・書棚） |

→ **暗さは正しい。足りないのは「情報密度」「光の演出」「奥行き」。**
明トーンの目標比率は 38% → **10%前後**に下げ、暗いシーンのリッチさを上げる。

### 1-2. 「不変の構造」と「可変の配色」

3本を比べて判明した最大の発見。**構造は完全に共通、配色だけがテーマから決まる。**

| | 不変（3本共通） | 可変（テーマ由来） |
|---|---|---|
| | 暗い基調＋グロー | **港区女子**: マゼンタ＋金（夜の街） |
| | 3層レイアウト | **菌類生態学**: 緑＋土茶＋琥珀（森と地中） |
| | 段階的reveal | **学歴**: 深紺＋緋色＋クリーム紙（記録・文書） |
| | 図解＝舞台上の物体 | |
| | 章タグ・大型タイポ | |
| | クリーム紙のエンドカード | |

→ 実装では**テーマに応じたパレット切り替え**を持たせるべき。

### 1-3. チャンネルは「1つの様式」ではなく**3つのレジスター**を行き来する

7本を横断して見ると、同じチャンネルの中に明確に異なる3つの絵作りがあり、
**1本の動画の中でも切り替わる**。どれか1つに寄せるのは誤り。

| レジスター | 代表 | 特徴 |
|---|---|---|
| **A. 情景イラスト** | 都会の孤独 / 隠居 / 英雄色を好む | 全画面のフラットな風景・室内。人物・建物・小物が実際に配置される。ここだけ彩度と明度が上がる |
| **B. 暗いデータ／タイポ** | 努力と才能18研究 / 正義と世代 | ほぼ黒。琥珀のグロー文字、棒グラフ・散布図・囲みカード |
| **C. 発光オブジェ** | 666と999 / 頭がデカい奴 | 暗闇に浮かぶ発光する球・柱・光条。数量を**物体の大きさ**で表す |

配分の実感は **A:B:C ≒ 4:4:2**。Bが続くと単調になるため、
数分おきにAの情景が挟まって呼吸をつくっている。

### 1-4. 字幕は焼き込み・常時表示

**ほぼ全コマに字幕がある。** 下部中央、白、1〜2行、うっすら影。
画面のいちばん下（高さの約92%）に置かれ、図解と重ならないよう
**主舞台は上寄り（縦の中央より少し上）に組まれている**。
→ 実装で下部に余白を確保していないと、参照チャンネルの構図にならない。

- 要素ごとの**小ラベル**が対象の真上に付く（「選び手」「明かす」「隠す」）。

## 5. シーンの型（実物カタログ）

★ = 現状の実装に無い、追加すべきもの

### A. 情景（Establishing）
- ★**夜景パノラマ**: 無数の窓明かりを持つビル群、奥にボケ光点
- ★**街路の一点透視**: 両側に建物、奥に消失点、中央に小さな人影
- ★**大階段＋光条**: 左右対称、奥の高所に金色の光源、斜めの体積光が交差
- ★**広間／柱廊**: 列柱が並び、奥に明るい扉
- ★**棚・陳列・書架**: 商品／瓶／張り紙／本が整然と並ぶ壁面（情報密度が非常に高い）
- ★**森の断面**: 地表線で上下に分割。上＝緑の樹冠、下＝土茶に白い菌糸／根が走る
- ★**山並みの夜景**: グラデーション空＋シルエットの稜線。大型タイポを重ねる土台に最適
- ★**明るい室内**（少数・約10%）: クリーム色の寝室・店内・教室。日常と対比の場面に限定

### B. 舞台（Staged）
- ★**台座＋スポットライト**: 人物が壇上に立ち、上から光の円錐が落ちる（3本すべてで多用）
- ★**段状の雛壇に並ぶ人々**: 色違いの人型が階段状に整列
- ★**円形アリーナ**: 楕円の縁に沿って人が並ぶ
- **群衆**: 多数の人型。ただし必ず**床面と奥行き**を持つ

### C. 節目
- ★**章タイトルカード**（実物: `channel/zoom-A.jpg` 右上）
  - ほぼ黒の画面に**楕円の柔らかい放射グロー**
  - 中央に**その章を象徴する小さな物体アイコン**（例: 雨戸＝琥珀色の2枚の板）
  - その下に `C h a p t e r  4` … **字間を大きく開けた小さなグレーのラテン文字**
  - さらに下に章題を**太い白文字**で1行（例: 雨戸の向こうの目）
  - 極端に要素が少ない。文字と1個の物体だけ
- ★**チャンネル・スティング**（実物: `channel/zoom-A.jpg` 左上）— **唯一の白背景**
  - **白い方眼紙**（薄い青灰色のグリッド）が全面
  - 「考えすぎる葦」を**極太ゴシック**で、ただし**各文字の内部に別々の絵が入っている**
    （「考」から人が生えている、「す」に山並み、「葦」に岩）
  - 左に**手描き線画の細長い人物（葦の擬人化）**が歩いており、文字の一部を兼ねる
  - 右下に**ハッチングで描かれた小さな岩**
  - スケッチブック／落書き帳の質感。動画の**途中**に挟まる（冒頭だけではない）
- ★**字間を開けた宣言**: `永遠 を 約束 し て は い な い` のように letter-spacing で重みを出す
- ★**結論カード**（実物: `channel/zoom-A.jpg` 右下）
  - 細い**角丸の枠線**だけの箱（塗りなし）を中央に置く
  - 箱の中は3段: 小さな字間広めのグレー注記（`1971-2021 SMPY・半世紀追跡`）→
    **太い白の本文で等式**（`才能ある人 = 測ってもらえた人`、**`=` だけ琥珀**）→
    小さなグレーの補足（`定義の二義性が、ここで反転する`）
  - 主張を「額に入れて提示する」型。動画の終盤に必ず出る
- ★**エンドカード**: クリーム色の紙質感、"Thank you for watching!"、チャンネルアイコン、
  高評価/低評価/コメントアイコン、SUBSCRIBEボタン、**動く手のカーソル**（7本すべて共通・完全に同一）

## 6. データ表現（最重要・現状との差が最大）

参照チャンネルの図解は**「グラフ」ではなく「舞台上の物体」または「記録文書」**として描かれる。

### 実物で確認できた型
- ★**横棒グラフ**（`frames-2/tile2_G_hbar_countries.png` が決定版）
  - ラベルは棒の**外側左**
  - 各行に**トラック**（薄いグレーの全幅バー）を敷き、その中を値バーが満たす
  - **強調行は金グラデ＋大きな白文字の値**、非強調行はスティールブルー＋小さめの値
  - 下端に**目盛り軸**（tick＋数値）
  - 行が**1本ずつ増える**
- ★**縦棒グラフ**: 金の主バーと小さな青のサブバーを対で並べる
- ★**折れ線／曲線**: 軸つき。終端に `2.1倍` のような**吹き出し注記**。点線の比較線を併置
- ★**ドーナツ／リング**: 中央に大きな%、セグメントは緑と金
- ★**ドット群（units）**: 「4人に1人」を琥珀の光点の格子で。該当分だけ強く光る
- ★**大きな数値**（`frames-3/tile2_M_bignum.png`）
  - 左上に**文脈タグ**（`1995→2025`＋小サブラベル）
  - 中央に**強くグローする巨大数字**、単位は別文字で隣に（`0` + `件`）
  - 直下に**サブラベル**
  - さらに下に**補助の時間軸**（tick＋年号）
- ★**光る柱（Column）**: 床に立つ金の縦柱。頭部に光球。柱の間を線が結び、傾きで関係を示す
- ★**天秤**: 物理的な天秤。皿に物を載せ、**実際に傾く**。%の注記を伴う
- ★**ピラミッド**: 3層（緑／橙／黄）の三角形。栄養段階・階層の可視化
- ★**象限／散布図**: 軸ラベル（学歴・人柄・収入）、光点、赤い強調ノード
- ★**ベン図**: 2円の重なり（マゼンタ／ブルー）
- ★**行列・ヒートマップ**: 小さな色付きバーを大量に並べ、一部を強調（`6位` を丸囲みで）
- ★**黒板**: 深緑の板＋金の額縁に数式や語を書く
- ★**紙の資料**: クリーム色の罫線入り用紙。机上・壁・書架に置かれる（3本共通の重要モチーフ）
- ★**地図**: 簡略化した陸地に地名ピン（東京・ソウル・ニューデリー）
- ★**国旗**: 国別比較の際に実物の旗を添える

### 第2次解析で新たに確認した型（実装優先度が高い）

- ★**発光する球＋光条＋ラベル箱**（`channel/zoom-B.jpg` 左上 / 666と999 32%）
  - 3つの**縁のぼけた発光する球**を横一列（青=999 / 深紅=4 / 深紅=666）
  - 各球の**真上から光の柱（縦のシャフト）**が降りる
  - 球の中に**ベージュの小さな名札**（数値）
  - 球の下に**細い枠線だけのラベル箱**（安い / 死 / 悪魔）
  - 球どうしを**細い横線**が結ぶ
  - → 3項の概念対比の決定版。現状の `columns`（2項）を3項に拡張する価値がある

- ★**球の大きさで数量を示す**（`channel/zoom-B.jpg` 左下 / 頭がデカい奴 42%）
  - 桃色の球2つ、**大きさの比がそのまま数量の比**
  - 球の内部に**無数の白い光点**（細胞・星）
  - 球の直下に**全角数字で大きく**（`５６億` / `１６３億`）字間広め
  - → `stat` の2値比較版。棒グラフより情緒がある

- ★**縦の目盛りゲージ＋増減の読み**（`channel/zoom-B.jpg` 右下 / 英雄色を好む 26%）
  - 画面右に**縦に積んだ十数個の細い目盛り**（下=青 → 上=橙赤のグラデーション）
  - その右に「小さなグレーのラベル ＋ ↓ ＋ 大きな白の%」を2段
  - 画面の他は**ほぼ空**。1オブジェクト＋1読み値だけ
  - → 「余白を恐れない」型。現状の実装は要素を詰めすぎている

- ★**人物が持つ棒＝量**（`channel/zoom-B.jpg` 右上 / 隠居 68%）
  - 左右に見出しを太い白文字で（`残された時間` / `解体の不安`）
  - 各見出しの下に人物が立ち、**手から水平の棒が伸びる**。棒の長さが量
  - 中央は**小さなブロックを積んだ縦棒の集合**（都市のシルエット兼グラフ）
  - 人物の足元に**楕円の光だまり**
  - → 抽象グラフを人物の身体動作に落とし込む手法

- ★**縦棒グラフは項目ごとに色を変える**（`channel/zoom-A.jpg` 左下）
  - 5本の縦棒が**それぞれ別の色**（紫・サーモン・緑・青灰・灰）。単一アクセント色ではない
  - 値は棒の**上**に白／琥珀、項目名は棒の**下**に小さく
  - 上部中央に小さなグレーの表題、下部に軸の説明
  - → 現状の `chart`（琥珀1色＋強調1本）とは設計思想が違う

- ★**units は枠付きパネルに入れ、進行マーカーを添える**（`channel/zoom-C.jpg` 左上）
  - 細い枠線の箱の中に、小さな人型グリフを9×6程度で整列
  - **箱の外・右側**に `≈0年目` の小ラベルと**琥珀の矢印 →**（時間が進むことを示す）

- ★**小物で埋めた俯瞰シーン**（`channel/zoom-C.jpg` 右上 / 666と999 16%）
  - 会議室を俯瞰。机にモニタ（中に赤青の棒グラフ）、壁に額入りのグラフが6枚、
    机上に紙・箱・ペンが散乱、中央上に**光る「?」**
  - → 情報密度の手本。背景の小物が「学術・調査」の記号として効いている

- ★**全画面の暖色内装**（`channel/zoom-C.jpg` 左下 / 英雄色を好む 53%）
  - 黄土色の壁、暗い梁、朱の柱、左右に**灯りのともった行灯**
  - 色違いの着物の人物が階段状に整列、奥の一段高い所に主
  - → レジスターAの最大の見せ場。暗いシーンが続いた後にこれを置いて緩急を作る

- ★**無数の窓のなかの一つだけが灯る**（`channel/zoom-C.jpg` 右下 / 都会の孤独 84%）
  - 画面全体が小さな青い窓の格子。中央の1枚だけが**暖色に灯った部屋**
  - → 「孤独」「例外」「発見」の汎用モチーフ

### 現状の実装との差
今の `chart` は平面的な棒グラフ1種のみ。上記のうち**横棒の作法（トラック・強調色分け・軸）**と
**大きな数値の作法（文脈タグ・グロー・補助軸）**だけでも実装すれば、質は大きく上がる。

さらに第2次解析を踏まえると、次の3点が現状との最大の乖離である:
1. **図解が「グラフ」に留まっている** — 参照は球・光条・人物の動作・物体の大小に翻訳している
2. **余白が足りない** — 参照は「1オブジェクト＋1読み値」で1シーンを成立させる
3. **情景（レジスターA）が無い** — 全編がBに寄っており、呼吸が作れていない

## 7. アニメーション技法

### 7-1. 最大の特徴：**1シーンを長く持たせ、その中で段階的に足す**
同じ構図が数十秒続き、その間に要素が**1つずつ**増える。
画面を切り替えて飽きさせるのではなく、**同じ画の中で情報が育つ**。

観測例:
- 横棒: 1行 → 3行 → 4行、と国が増える
- 光る柱: 左の柱 → 右の柱 → 結ぶ線 → 数値 → 凡例
- 天秤: 水平 → 傾く（%の注記が出る）
- 街路: 建物のみ → 窓に明かりが灯る → 人影が現れる
- 雛壇: 数人 → 全段が埋まる → 一部だけ色が変わる

→ **実装方針**: シーン尺を長くとり、`durationInFrames` の 0% / 20% / 45% / 70% で
子要素を順次 reveal する設計にする。

### 7-2. 常時動いている背景
- ボケ光点のゆっくりした浮遊
- 窓明かりの**ランダムな明滅**
- 薄いヘイズの流れ
- スポットの光条のわずかな揺れ

### 7-3. カメラ
- ごく緩やかな**押し込み／引き**（1シーン中に数%スケール変化）
- 情景では**横パン**。街路や棚を舐めるように

### 7-4. 要素の入り
| 対象 | 入り方 |
|---|---|
| 人物・物体 | 下から浮上＋フェード／スポットが先に点いてから中身 |
| 数値 | カウントアップ＋グローの立ち上がり |
| 線 | 左から右へ描画 |
| 棒 | 床（またはトラック左端）から伸長、わずかなオーバーシュート |
| ラベル | フェード＋数px下から |
| 天秤・シーソー | 実際に傾く（イージングつき） |

### 7-5. やってはいけないこと
- ❌ シーン転換で**真っ黒を経由**する（修正済み）
- ❌ 中央に大きな文字だけ（参照チャンネルにはほぼ無い）
- ❌ 平坦な背景に浮いたアイコン1個
- ❌ 情報密度が低いまま数秒放置

## 9. 人物の描き方（第2次解析で判明）

現状の実装は「顔のない縦長のシルエット」だが、実物はもう少し具体的である。

- 頭は**丸**、体は**単純な台形／円錐**。手足は細い線か省略
- **服に色がある**（濃緑・紺・臙脂・青）。全員が黒シルエットではない
- 顔は**のっぺりした肌色の面**。目鼻が点で入ることもある。髪は暗い塊
- 足元にほぼ必ず**楕円の光だまり**（接地感を出す）
- 群衆は**同じ人型を色違いで並べる**。整列（列・階段・円弧）させることが多い
- 単独の人物は**画面の下1/3・やや左右どちらかに寄せる**。中央にはあまり置かない
