# 映像スタイルガイド（参照: 考えすぎる葦）

本チャンネルの映像を再現するための、実物解析にもとづく決定版スタイルガイド。
以後の映像実装・プロンプト設計は**すべてこの文書を基準**にする。

## 解析ソース

- 動画: 「なぜ港区女子はモテるのに結婚できないのか【進化心理学×情報経済学】」
  （考えすぎる葦 / 2026-07-19 / 22分45秒 = 1365秒）
- 抽出: 全編を約9.75秒間隔でサンプリングした**140フレーム**（`frames/grid-00〜05.jpg`）
  ＋拡大した代表コマ6点（`frames/tile_*.png`）
- 制約: YouTube本体のダウンロードがCDNで拒否されたため、ストーリーボード画像を使用。
  **構図・配色・シーン構成・段階的な演出の変化は読み取れるが、
  1秒未満の細かい動き（イージング等）は直接観測できていない。**
  モーションの記述は、同一シーンが複数コマにまたがる変化からの推定を含む。

## 1. 最重要の結論（これまでの実装の誤りを含む）

### ❗ 「明るい背景を増やす」は誤りだった

以前ユーザーの「ずっと暗い背景」という指摘を受け、明トーンを全体の約38%まで
機械的に引き上げた。**しかし実物は圧倒的に暗い。** 明るいシーンは全140コマ中
15コマ前後（**約10〜12%**）にすぎない。

真の差は明暗ではなく**「暗さの質」**である。

| | 現状の実装 | 参照チャンネル |
|---|---|---|
| 背景 | 平坦な放射グラデーション1枚 | 奥行きのある**情景**（夜景・広間・街路・棚） |
| 光 | 中央のぼんやりした光 | **体積光**（スポットの光条）・窓明かり・ボケ |
| 主役 | 中央に浮くアイコン1個 | 環境の中に**配置**された人物・物体 |
| 密度 | 要素1〜2個 | 背景に無数の小要素（窓・人・棚・張り紙） |

→ **暗さは正しい。足りないのは「情報密度」と「光の演出」と「奥行き」。**
明トーンの目標比率は 38% → **12%前後**に下げ、代わりに暗いシーンの
リッチさを上げるべき。

## 2. 全体の雰囲気（トーン&マナー）

**「夜の劇場」**。静かで、思索的で、どこか演劇的。
視聴者は暗い客席から、照明の当たった舞台上の出来事を眺めている。

- 徹底して**シネマティック**。ワイドな引きの画、強い一点透視、左右対称の構図。
- 画面はほぼ常に**薄いヘイズ（靄）**を含み、光源が滲む。
- 人物は**極端に簡略化されたフラットなシルエット**（頭が丸い縦長の塊）。
  顔・表情は一切描かない。だが**必ず「場所」の中に立っている**。
- 静止画的な美しさがあり、1コマを止めても絵として成立する。

## 3. カラーパレット

### 基調（背景）
- `#0a0d14` 〜 `#141a26` … 深いネイビー／墨色（最頻出）
- `#1a0f18` 〜 `#2a1420` … 暗いワインレッド／紫（情念・夜の街）
- 純黒 `#000000` は**幕間の一瞬**にのみ使う

### アクセント（光）
- **アンバー／ゴールド** `#e8b563` `#ffd9a0` … 主役の光。窓明かり、スポット、柱
- **マゼンタ／ピンク** `#e8558f` `#ff7ab0` … 欲望・夜の街・強調
- **ティール／シアン** `#5ad6c8` … 理性・データ・対比
- **レッド** `#e8544a` … 警告・負の値・烙印
- **グリーン** `#4ad17a` … 正の値・データの伸長

### 文字
- 見出しラベル: 純白 `#ffffff` ＋ **黒の縁取り**（背景が明暗どちらでも読める）
- 字幕: 白 ＋ 黒縁、画面下部中央、1〜2行
- 数値: アクセント色（正=緑/金、負=赤）

## 4. 画面レイアウト（3層構造）

```
┌─────────────────────────────────┐
│  ① 見出しラベル（上部）             │  例:「─ 夜の街 ─」「統計的差別」「価値の逆転」
│     白文字＋黒縁。時に飾り罫を伴う      │
│                                 │
│  ② 主舞台（中央〜全面）             │  情景／図解／人物。ここが主役
│     奥行きのある環境の中に要素を配置    │
│                                 │
│  ③ 字幕（下部中央）                │  白＋黒縁、1〜2行、小さめ
└─────────────────────────────────┘
```

- ①の見出しは**常時は出ない**。概念の切り替わりで出て、しばらく残る。
- 要素ごとの**小ラベル**が対象の真上に付く（「選び手」「被選手」「明かす」「隠す」）。

## 5. シーンの型（実物カタログ）

観測された画作りを分類する。**今の実装に足りないものに ★** を付す。

### A. 情景（Establishing）
- ★**夜景パノラマ**: 無数の窓明かりを持つビル群。ボケ光点が奥に散る
- ★**街路の一点透視**: 両側に建物、奥に消失点、中央に小さな人影
- ★**大階段＋光条**: 左右対称、奥の高所に金色の光源、斜めの体積光が交差
- ★**広間／柱廊**: 列柱が並び、奥に明るい扉
- ★**棚・陳列**: 商品／瓶／張り紙が整然と並ぶ壁面（情報密度が非常に高い）
- ★**明るい室内**（少数）: クリーム色の寝室・店内・教室。日常・対比の場面に限定

### B. 舞台（Staged）
- ★**台座＋スポットライト**: 人物が壇上に立ち、上から光の円錐が落ちる
- ★**段状の雛壇に並ぶ人々**: 色違いの人型が階段状に整列（比較・分類の可視化）
- ★**円形アリーナ**: 楕円の縁に沿って人が並ぶ（社会・市場の比喩）
- **群衆**: 多数の人型。ただし必ず**床面と奥行き**を持つ

### C. 図解（Diagram）— ここが決定的に違う
参照チャンネルの図解は**「グラフ」ではなく「舞台上の物体」**として描かれる。

- ★**光る柱（Column）**: 床に立つ金色の縦柱。頭部に光球。
  柱の間を細い線が結び、数値が浮かぶ（傾き＝関係の逆転を表現）
- ★**シーンに埋め込まれた棒グラフ**: 夜景のビルを背にして棒が床から生える。
  半透明の「参照バー」と実体バーを並置。値は棒の上に大きく色付きで
- ★**象限／散布図**: 軸ラベル（学歴・人柄・収入）、光点、赤い強調ノード
- ★**掲示板・カード列**: 複数の札が壁に並び、順に光る
- **砂時計・天秤**: 概念のメタファーを大きく1つ

### D. 節目
- ★**章タイトルカード**: 暗転気味の画面に小さな額縁と章名（「最後の換金所」）
- ★**エンドカード**: クリーム色の紙質感、"Thank you for watching!"、
  チャンネルアイコン、高評価/コメントアイコン、SUBSCRIBEボタン、**動く手のカーソル**

## 6. アニメーション技法

### 6-1. 最大の特徴：**1シーンを長く持たせ、その中で段階的に足していく**
同じ構図が何コマ（＝数十秒）も続き、その間に要素が**1つずつ**増える。
画面を切り替えて飽きさせないのではなく、**同じ画の中で情報が育つ**。

観測例:
- 光る柱: 左の柱 → 右の柱 → 結ぶ線 → 数値 → 右側の凡例、と順に出現
- 棒グラフ: 参照バー → 実体バーが伸びる → 値ラベル → 2本目 → 対比の色
- 雛壇の人々: 数人 → 全段が埋まる → 一部だけ色が変わる
- 街路: 建物のみ → 窓に明かりが灯る → 人影が現れる

→ **実装方針**: シーンの尺を長くとり、`durationInFrames` に対して
0%/20%/45%/70% のタイミングで子要素を順次 reveal する設計にする。

### 6-2. 常時動いている背景要素
- ボケ光点のゆっくりした浮遊
- 窓明かりの**ランダムな明滅**（点いたり消えたり）
- 薄いヘイズの流れ
- スポットライトの光条のわずかな揺れ

### 6-3. カメラ
- ごく緩やかな**押し込み（push-in）／引き**。1シーン中に数%スケールが変化
- 情景では**横パン**。街路や棚を舐めるように

### 6-4. 要素の入り
- 人物・物体: **下から浮上＋フェード**、または**スポットが先に点いてから中身**
- 数値: **カウントアップ**
- 線: **描画（左から右へ伸びる）**
- 棒: **床から伸長**、わずかなオーバーシュート
- ラベル: フェード＋数px下から

### 6-5. やってはいけないこと
- ❌ シーン転換で**真っ黒を経由**する（既に修正済み）
- ❌ 中央に大きな文字だけ（参照チャンネルにはほぼ無い）
- ❌ 平坦な背景に浮いたアイコン1個
- ❌ 情報密度が低いまま数秒放置
